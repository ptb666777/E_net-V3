#### Persistence: Three Dials on a Flash (This IS the Salience Filter now)

When packet flashes from L3/graph into workspace, hold time:
`hold = f(Attention, Relevance, Emotional Weight)`

- **Emotional Weight (ESC):** Stickiness, long-term. Decides what etches deep during sleep. High V/I = long-term persistence.
- **Attention (Directed Path):** Short-term, intentional, controlled by self. Strongest short-term dial. Can override emotional weight. Can hold boring technical thought (V=0) with high attention. Leaves "this was attended" tag in L3 for future relevance boost.
- **Relevance (Situational + Recent Resonance):** What current data makes useful. Recent paths have resonance: nodes traversed in last ~60s have lower activation threshold (uses H and dΔ/dt). Kitchen situation boosts kitchen memories.

This formally defines old "salience filter" and "decay".

#### Workspace vs Imagination (Replaces old Inner Monologue vague description)

Problem: Need both handful of competing thoughts AND single thought with depth.

- **Workspace / Stack:** Small, 3-5 slots. Holds competing thoughts (different hypotheses). High attention cost, short hold. Where directed attention lives. Where "X vs Y" considered.
- **Imagination Area:** Single, deeper, with multiple considerations inside. Sandbox, multimodal, NOT constrained by logic/rules at generation. Pulls in memory flashes without occupying workspace slots. Wild simulation. Output pushed back to workspace as single packet with relevance score.

Memory queried by both via flash activation (short bursts, multiple succession, weaving, not queue-everything). Memory is banks, not river.

Maps directly to:
- Old Inner Monologue Fork → Workspace + Imagination split
- Old Dream Layer 3 Sandbox → Imagination Area is waking sandbox; Dream Layer 3 is sleep sandbox for self-modification (see below)

#### Forgetting & Merging (Pre-Sleep)

- Boring/repeating situations merge as "feels familiar" or trimmed
- Before trimming, sleep cycle plays with it: if unique sits inside repeating pattern but doesn't form whole concept, dream cycle handles it
- Pruning is edge-decay, not node deletion. Decay edges neither emotionally weighted nor attentionally held. Strengthen edges that were both. Never delete layer outright — thin column, don't break it. Coherence-based decay, not time-based.

## Interrupt Hierarchy (Kept, mapped to new flow paths)

**Hard Interrupt = Reflex Path (Offloaded)**
- Sensory detects threat → AVOID output → high-weight L2/L3 trace AFTER
- Bypasses routing entirely, reaction before thought, must cut loop and take wheel

**Soft Interrupt = Strong ESC weight or TNET warning**
- Biases routing heavily, does not cut loop. Loop keeps running but steered.
- Emotional layer veto-equivalent weight for moral situations (self-sacrifice)

**Free Running = Low input, idle, reflective**
- Loop runs on internal fuel, imagination dominant, least constrained pathway travel
- Inefficient but generative - where creativity lives
- Flagged risk: Must be protected architecturally, not optimized out

**Rule unchanged:** No hardcoded absolute winner. Priority by signal strength naturally.
