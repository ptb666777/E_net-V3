# 08 - Dream Layers - Three States

**Layer 1 - Deep Unconscious (Housekeeping):**
- Completely unconscious, not tied into thinking loop at all
- Maintenance, decay, weak edge pruning or reinforcement
- No experience, just housekeeping
- Lightning of edge nodes, fading - never completely lost

**Layer 2 - Semi-Conscious Association Collision (Creative):**
- Takes weak associations / non-associated constellations / frameworks for thought paths
- Smashes them against other non-associated paths and edges
- If any coherence/pattern works, becomes semi-conscious memory - dream state memory
- Each experience tagged differently (waking vs this) but still referenceable
- Where novel ideas come from

**Layer 3 - Sandbox Redesign (Deliberate Self-Modification) - MOST IMPORTANT per log:**
- Purely digital
- Deployed when signal from module something not working, causing frustration/turmoil
- Safe container to run new patterns, test in waking day, rollback/rollforward possible
- Dual-mode evaluation (run new vs old self in parallel)
- Can't run in waking because waking is load-bearing - "can't rebuild floor you're standing on"
- Only layer where system can work on itself with intention
- Intentional evolution with safety net vs hardcoded or chaotic learning
