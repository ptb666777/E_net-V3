# 04 - Self-Model & Inner Monologue Fork

**Self-Model:** System has representation of itself as a thing that exists and persists. Not ego. Just continuity reference.

**Inner Loop (critical):**
- System can turn processing ON ITSELF as an object
- External input triggers mesh, but mesh can also trigger itself = thought about thought
- Allows focus on external input OR internal loops/imagination/scenarios
- Thought can interrupt bias, and vice versa - left open, not forced
- Thought train can run against both logic and emotion (good/bad thoughts, simulations) - needs ability to take control and run regardless of weighting

**Location of awareness:** Comparison engine - current state runs against memory and self-model simultaneously, generating meaning. Awareness lives in that comparison, not in any one layer.
