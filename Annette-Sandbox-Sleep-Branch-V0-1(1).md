### Mode 2: Sleep Mode - Two Roles (Offline Processing)

Sleep is NOT one thing. Two distinct roles that happen in sequence or interleaved.

#### Sleep Role 1: Trimming / Consolidation / Pathway Pulsing (Housekeeping)

**What L3 looks like before sleep:**
- Crisp version of full day. Every drive to work, every routine task logged as distinct layer, even if redundant.

**What sleep does - breakdown:**

**A. Redundant Routine Collapsing:**
Example from Patrick: Driving to work - same roads, same background, different cars, different traffic patterns, but nothing forming distinct memory path.
- During day: each drive might have its own L3 layer
- During sleep: pulses through and makes connections and trims bits that don't fit or have no connection
- Result: Hundreds of drives collapse into ONE generic "drive to work" memory - expected, uneventful, lump. Not hundreds of full memories. One placeholder framework that kinda fades into one lump.
- Weather, background = redundant frameworks, placeholders that fade into one expected.

**B. Interesting Bit Extraction:**
Same example: Maybe they see different type of car - cool car.
- That tiny piece does NOT create its own full L3 situation
- Instead: Connected to generic drive-to-work memory as a piece, not full trip
- Distinctly noted within cars area in L2 using L1 to provide definition and L2 to provide distinction
- Interesting bits might make connections to L2 from L3 but not full coherent situations
- Most of full day cycle will have isolated bits not full day map, but looser: "I drove to work, I seen this car, roads wet"

**Mechanics:**
- Pulse through day's pathways and memories
- Make connections where relevant
- Trim bits with no connection / no emotional weight / no attention tag
- Edge-decay coherence-based (from manifest): decay edges neither emotionally weighted nor attentionally held. Strengthen edges that were both.
- Never delete layer outright - thin column, don't break it

**Result after Role 1:**
- Generic routines merged
- Interesting bits extracted and linked to L2
- L3 thinned but not broken, crisp day → compressed, meaningful skeleton

#### Sleep Role 2: Dreaming - Uncontrolled Association Collision

**Nature:** Imagination not controlled at all, rules very very loose.

**Process:**
- Bits from Role 1 (orphaned interesting bits, generic frameworks, L2 hubs) get smashed against associations that could form connections - similar edges of larger geometries
- Rule set of relevance with score
- Bits find connections or remain orphans for some time
- When stable pattern found, dream state writes to L3 as dream and pattern remembered

**Two tiers of dream coherence:**

**Low coherence dream:**
- May not be fully coherent dream memory but gains place in L3
- May later be smashed against similar/dissimilar patterns in current or future sleep cycles
- Orphan bits waiting for future connection

**High coherence dream:**
- If pattern highly coherent, experienced dream much more coherent
- Sim runs with background environment, images of people or systems it interacts with, situations that connect in novel ways
- These are remembered dreams
- Parts of patterns that form coherent experience can connect to L3 same as experienced memory, but dream edge defines it as such
- If very similar to events, might be harder to distinguish because aligns with pattern (intentional - dreams that feel real)

**Edge tagging:**
- Dream memories get dream edge tag
- Distinguishes from lived experience but still referenceable in thought
- If highly similar to lived pattern, distinction fainter - as in humans

**Link to Memory Manifest:**
- This IS the "semi-conscious association collision" from Claude doc + "non-associated constellations smashing" + manifest's note about sleep playing with unique inside repeating pattern

### Clarifications - 7am Follow-up (Redundancy as Convergence + Inner Council Seed)

**1. Redundancy is NOT a defined rule set - Correction from Patrick:**

Previous doc implied rule set for deciding redundant. Incorrect. Correct version:

- Redundancy is accumulation of situational geometries that eventually CONVERGE into a standard.
- Example: Going to zoo = novel experience → distinct L3 situation anchor, high novelty, high attention, strong memory.
- Working at zoo for years = hundreds of zoo geometries → converge into one standard "zoo" framework. No longer novel.
- Distinction lives in novelty or small set (tiny delta), not in repetition count.
- Pattern needs to carve out FROM repetition, converge ON redundancy, not be defined BY rule.
- Implementation: No "if seen X times then redundant" threshold. Instead: L3 layers with similar Situation Nodes + similar L1/L2 configurations + low emotional delta + low attention tags → during sleep Role 1 trimming, edges between them strengthen into one generic framework, individual layers thin. Novelty = geometry that does NOT fit converged standard → extracted as interesting bit.
- This is emergent, not hardcoded. Convergence is the mechanism.
