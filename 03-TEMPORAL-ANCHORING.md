# 03 - Temporal Anchoring / Clock

**Not a clock.** Relational time, not timestamp.

Examples from log:
- Sun position, cascade of day: waking, bathroom, getting ready, day events cascading
- Heartbeat as small tick (internal reference)
- Time perception changes with focus

**Implementation idea:** Temporal landmark layer - "this happened before that", "this feels like morning". Sequence awareness, not absolute time.

**Why it matters:** Memory organizes by sequence/association, not date. Anchoring provides reference without forcing chronological precision.
