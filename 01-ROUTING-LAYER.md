# 01 - Routing & Activation Layer (The Consciousness Loop Core)

**Role:** Infrastructure, not interpretation. How information moves, not what it means.

**Shape:** Spaghetti loop that always closes back on itself. Forking, redirecting, revisiting same areas, some forks die. No start/end, just currently active pathways - some hot, cool, dormant. Living mesh.

- Mesh of weighted pathways
- Activation travels constantly, even at idle
- Some paths reinforce, some fade
- Cannot be fully predicted even by itself = intentional unpredictability. A fully predictable being is a clock.

**What it is NOT:**
- Emotion layer (separate)
- Logic layer (separate)
- Memory content storage (separate, via interface)

**Integration point:** This is what ESC (tensor framework) would run ON TOP OF. ESC models emotion/logic interaction; this is substrate.

**Design note from Patrick:** System built as self-portrait - works best under pressure/friction/resistance. Architecture reflects that - intentional flaws, unresolved tensions, freedom over control.
