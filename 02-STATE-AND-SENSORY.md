# 02 - State Layer & Sensory Embodiment Inputs

**State Layer:** What is happening right now, incoming, being processed.

**Sensory inputs (forked into mesh):**
- External: vision, hearing, other senses
- Internal (for local model): heat, memory usage, CPU load, "term bass" [likely temp/battery or system stats]
- These hit mesh from outside and inside simultaneously

**Design principle:** Keep loose. Not hard data dumps, but references.

**Seam to memory:** Memory substrate needs to know which state the loop was in when a memory was formed. Context travels with memory.
